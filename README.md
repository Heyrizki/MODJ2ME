# 🕹️ MODJ2ME — Retro Java Game Mods
**By Rizki Adi Saputra | Merauke, Papua Selatan**

---

## 📖 Tentang Proyek
**MODJ2ME** adalah koleksi modifikasi game lawas **Java ME (J2ME)** yang dibuat khusus untuk **kesenangan dan bernostalgia**. Proyek ini hadir untuk menghidupkan kembali kenangan masa kejayaan game ponsel era tombol fisik, dengan penyesuaian layar serta modifikasi bahasa agar nyaman dan seru dimainkan kembali di emulator modern.

> *"Hanya untuk kesenangan dan nostalgia masa lalu, ges!"*

---

## 🚀 Rilis Game (Featured Mod)

### 🧟 Resident Evil Uprising J2ME (Bahasa Indonesia)
* **Resolusi Layar:** `360x480` (Pas untuk Android)
* **Bahasa:** Indonesia
* **Genre:** Action / Survival Horror
* **Status:** Siap dimainkan

---

## ✨ Fitur & Modifikasi
* **Cheat Manual di Main Menu:** Akses menu cheat dengan mudah langsung dari menu utama game.
* **Cheat Lengkap (All-in-One):** Membuka semua senjata (*all weapon*), amunisi (*ammo*), serta seluruh item termasuk *health* (darah).
* **Karakter Spesial:** Hadir dengan pilihan karakter **Jill Valentine** dan **Mamang Leon Kennedy**.
* **Full Bahasa Indonesia:** Seluruh teks dan cerita sudah diterjemahkan ke Bahasa Indonesia yang ringan dan mudah dimengerti.
* **Perbaikan Kontroler:** Perbaikan pada tombol dan kontroler yang sebelumnya sempat hilang atau tidak responsif.
* **Layar Presisi (`360x480`):** Ukuran layar sudah disesuaikan agar pas dan nyaman dimainkan di emulator Android masa kini.

## 🎮 Cara Download & Bermain
1. **Unduh Game:** Klik link repositori berikut untuk mengunduh file game:  
   👉 **[Download Resident Evil Uprising - Bahasa Indonesia](https://github.com/Heyrizki/MODJ2ME/tree/Resident-Evil-Uprising-Bahasa-Indonesia)**
2. **Pasang Emulator:** Gunakan emulator J2ME di Android (disarankan menggunakan **J2ME Loader**) atau **Kemulator** untuk PC.
3. **Mainkan:** Buka file `.jar` yang sudah diunduh melalui emulator, atur resolusi layar ke **360x480**, dan selamat bernostalgia!
