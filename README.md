---

## 📖 Tentang Proyek  
**MODJ2ME** adalah koleksi modifikasi game lawas **Java ME (J2ME)** yang dibuat khusus untuk **kesenangan dan bernostalgia**. Proyek ini menghadirkan kembali kenangan masa kejayaan game ponsel era tombol fisik, dengan penyesuaian layar serta modifikasi bahasa agar nyaman dan seru dimainkan di emulator modern.  

> *"Hanya untuk kesenangan dan nostalgia masa lalu, ges!"*

## 🎮 Cara Bermain  
1. Unduh file `.jar` dari tautan di atas.  
2. Pasang emulator J2ME di Android atau PC Anda (disarankan **J2ME Loader** untuk Android atau **Kemulator** untuk PC).  
3. Buka file `.jar` melalui emulator, atur resolusi layar ke **360x480 landscape**, lalu aktifkan cheat sesuai instruksi.  
4. Selamat bernostalgia dengan naga kesayangan Anda!
