# 🕹️ MODJ2ME — Retro Java Game Mods
**By Rizki Adi Saputra | Merauke, Papua Selatan**

---

## 📖 Tentang Proyek
**MODJ2ME** adalah koleksi modifikasi game lawas **Java ME (J2ME)** yang dibuat khusus untuk **kesenangan dan bernostalgia**. Proyek ini hadir untuk menghidupkan kembali kenangan masa kejayaan game ponsel era tombol fisik, dengan penyesuaian layar serta modifikasi bahasa agar nyaman dan seru dimainkan kembali di emulator modern.

> *"Hanya untuk kesenangan dan nostalgia masa lalu, ges!"*

---

## 🚀 Rilis Game (Featured Mod)

### 🧟 Resident Evil Uprising J2ME (Bahasa Indonesia)
* **Resolusi Layar:** `360x480`
* **Bahasa:** Indonesia
* **Genre:** Action / Survival Horror
* **Status:** Siap dimainkan

Nikmati ketegangan klasik *Resident Evil Uprising* dengan terjemahan Bahasa Indonesia dan penyesuaian layar **360x480** yang pas untuk emulator masa kini.

* 🔗 **Unduh Game:** [Resident Evil Uprising - Bahasa Indonesia](https://github.com/Heyrizki/MODJ2ME/tree/Resident-Evil-Uprising-Bahasa-Indonesia)

---

## 🎮 Cara Bermain
1. Buka tautan unduhan di atas dan unduh file `.jar` yang tersedia di dalam folder.
2. Pasang emulator J2ME di Android atau PC Anda (disarankan menggunakan **J2ME Loader** untuk Android atau **Kemulator** untuk PC).
3. Buka file `.jar` melalui emulator, atur resolusi layar ke **360x480**, dan selamat bernostalgia!
